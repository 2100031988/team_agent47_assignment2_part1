# Security Policy

## Supported Versions

NumCompute is actively maintained and security updates are provided for the latest stable release.

| Version                | Supported |
| ---------------------- | --------- |
| Latest Release         | ✅         |
| Previous Major Release | ✅         |
| Older Releases         | ❌         |

We recommend that all users upgrade to the latest available version to receive security fixes, performance improvements, and new features.

## Reporting a Vulnerability

The NumCompute team takes security issues seriously and appreciates responsible disclosure.

If you discover a security vulnerability, please report it privately by creating a security advisory through GitHub or by contacting the maintainers directly.

When reporting a vulnerability, please include:

* A clear description of the issue
* Steps to reproduce the vulnerability
* The affected NumCompute version(s)
* Any proof-of-concept code or screenshots (if applicable)
* Suggested mitigations (optional)

### What to Expect

* **Acknowledgement:** Within 3–5 business days
* **Investigation:** The issue will be reviewed and validated
* **Resolution:** If confirmed, a fix will be developed and included in a future release
* **Disclosure:** Public disclosure will occur only after a fix is available

Please do **not** disclose security vulnerabilities publicly until they have been investigated and resolved.

We appreciate the efforts of security researchers and contributors who help keep NumCompute safe and reliable for the community.
